# ASHFALL System Map

This is intentionally high-level. Use the active job to choose what to inspect.

- `artifacts/ashfall/` — existing browser RPG and playable surface.
- `engine/` — Java/Gradle simulation foundation.
- `docs/` — design bibles, workflow, roadmap, decisions, and job records.
- `attached_assets/` — supplied briefs and references.

## Boundaries

- Jobs 002–004: coordinate, grid, and chunk-storage contracts.
- Job 005: deterministic basic world generation.
- Job 006: bounded chunk streaming.
- Jobs 007–018: early playable vertical slice.
- Job 019: generated opening history/lore and map-based starting location.

Never open every listed directory during orientation.
