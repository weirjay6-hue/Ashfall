Before implementation:

1. Do not mount, clone, import, or copy the full game repository.
2. Read only the control files in this folder.
3. Do not scan the game source, assets, or entire world during orientation.

5. Work on one bounded job only.
6. Inspect only the smallest relevant file set.
7. Test, update state, commit, push, and stop.

secrets flow. Never paste an access token into ordinary chat.
