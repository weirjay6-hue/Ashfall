# Vertical Slice

The first meaningful game is deliberately small: one player, several chunks,
simple terrain, exploration, a simple NPC, one outpost, one creature, combat,
loot, inventory, equipment, a small dungeon, and save/load.

Success means the player can start, move, explore, discover, encounter danger,
make a meaningful decision, fight or escape, receive a reward, improve, save,
load, and continue exploring. The existing browser game is the current
playable surface; the Java engine is being built toward this slice.
