# Simulation Bible

Use simulation LOD:

- Level 0: player bubble with detailed movement, NPCs, creatures, combat,
  interactions, weather, and environment.
- Level 1: nearby world with reduced schedules, wildlife, economy, weather,
  population, and events.
- Level 2: distant world with abstract production, food, resources, trade,
  factions, and conflict.
- Level 3: extremely distant world represented by statistical events.

When the player approaches, abstract state becomes detailed state without
breaking continuity. Every important system should be able to affect another
system through clean interfaces or events.
