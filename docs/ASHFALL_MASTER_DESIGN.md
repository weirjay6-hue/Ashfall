# ASHFALL Master Design

ASHFALL is a single-character open-world RPG built around living inside a
persistent simulated world. The player explores, takes risks, fights or
flees, gathers, trades, improves, and creates consequences. The player does
not directly command armies, settlements, factions, populations, or economies.

## North star

The world should feel larger than the player and should continue existing when
the player is not present. Systems should interact so that world events create
stories rather than isolated scripted content.

## Development order

Foundation → tiny world → player → exploration → danger → combat → loot →
equipment → dungeon/outpost → save/load → vertical-slice playtest → deeper
simulation.

Simulation exists to improve player experience. It is not the product by
itself.
